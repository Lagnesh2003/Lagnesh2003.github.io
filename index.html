ActiveImitation learning · VLASim + real arm

VLA policies on the SO-101 arm, sim to real

A full pipeline on a low-cost 6-DoF arm: MuJoCo task, IK expert, demonstrations, ACT training and evaluation, then a real leader–follower arm pair for real data and VLA fine-tuning.

  • 74%ACT success on unseen episodes; replanning every 10 steps instead of 50 raised it from 58%
  • 95%scripted IK expert success with DART noise (100% without noise)
  • ~7×faster demonstration rendering after profiling found it running on the integrated GPU

ActiveReinforcement learningHardware build

saferl-lab: sample-efficient RL for real robots

PPO and SAC on a GPU-simulated Furuta pendulum (swing-up and balance), compared against LQR and energy-based control under a strict 10-seed protocol. A real pendulum is being built to test them.

  • 100%PPO success, 10/10 seeds, with higher return than a hand-designed controller (479 vs 435)
  • 0.15Msteps for SAC with LayerNorm critics to reach 100% success, about 15× fewer than PPO
  • 66 sper 20M-step PPO run on a laptop GPU, down from 6 min, using CUDA graphs
  • PPO
  • SAC
  • MuJoCo Warp
  • CUDA graphs
  • LQR / iLQR
  • Domain randomization

ActiveDeep learningWorld models

Deep learning from scratch, through world models

Backprop, optimizers, normalization, LSTM and attention written by hand and checked against PyTorch, all applied to one problem: a learned dynamics model of the Furuta pendulum.

  • ~2000×lower one-step error than the best linear model
  • 14×lower test error with a 4.2M-parameter SimBa model; 50-step rollout error 0.176 → 0.078 rad
  • 20 µsof GPU work per Transformer prediction, using a hand-written Triton KV-cache kernel
  • PyTorch
  • Transformer
  • LSTM
  • SimBa
  • Triton
  • Uncertainty
